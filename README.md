# PingX - Instant & Secure Messaging

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Bhargavikintali/pingx)

PingX is a modern, ultra-responsive messaging web application and Android app featuring unique 8-digit PingX ID peer-to-peer authentication, instant connection requests, real-time simulated chatting, voice messaging, and integrated Google Meet video calling.

## ✨ Features

- **Unique PingX ID**: 8-digit unique ID generation upon registration.
- **OTP Verification**: Secure 4-digit code activation flow with auto-fill.
- **Connection Requests**: Send & receive peer connection requests with purpose/reason dialogs.
- **Interactive Chat**: Fluid chat interface with timestamps, read ticks, and automatic replies.
- **Voice Notes**: Simulated audio recording with animated waveform and timer.
- **Google Meet Integration**: Direct 1-tap video calling.
- **Dark & Light Mode**: Fluid responsive UI with dynamic gradients (`#4A00E0` to `#8E2DE2`).
- **PWA Ready**: Can be installed on mobile home screens as a native application.
